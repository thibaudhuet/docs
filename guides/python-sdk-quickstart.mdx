## Planned features

The SDK will wrap the Insights API with:

- **Automatic token refresh** — no manual token management
- **Typed responses** — Pydantic models for all API responses
- **Pandas integration** — `.to_dataframe()` on any series response
- **Async support** — `asyncio`-compatible client via `httpx`
- **CLI tool** — `simcel kpis pnl --plan plan_9xKz2 --scenarios ...`

## Expected interface

```python
from simcel import SimcelClient

client = SimcelClient(api_key="sk_live_...")

# Typed, with IDE autocomplete
pnl = client.insights.pnl_summary(
    plan_id="plan_9xKz2",
    scenario_ids=["scen_abc", "scen_def"],
    interval="FY",
    currency="EUR",
)

# Pandas integration
df = pnl.to_dataframe()
print(df[["scenarioName", "ebit", "ebitPercent"]].to_string())
```
