## Prerequisites

- A SIMCEL account with at least one active Plan
- OAuth2 client credentials (`client_id` and `client_secret`) or an API key

---

## Step 1: Get a token

Use OAuth2 Client Credentials or exchange your API key for a short-lived bearer token.

```bash OAuth2 (client credentials)
curl -X POST https://app.simcel.io/api/oauth/v1/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials&client_id=YOUR_CLIENT_ID&client_secret=YOUR_CLIENT_SECRET&scope=insights:read plans:read"
```

<CodeGroup>
```bash API key (cURL)
curl -X POST https://app.simcel.io/api/auth/v1/token \
  -H "Content-Type: application/json" \
  -d '{
    "apiKey": "sk_live_your_api_key_here"
  }'
```

```python API key (Python)
import requests

resp = requests.post("https://app.simcel.io/api/auth/v1/token", json={
    "apiKey": "sk_live_your_api_key_here"
})

token = resp.json()["accessToken"]
print(token)
```

```javascript API key (Node.js)
const resp = await fetch("https://app.simcel.io/api/auth/v1/token", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ apiKey: "sk_live_your_api_key_here" }),
});

const { accessToken } = await resp.json();
```
</CodeGroup>

**Response:**

```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expiresIn": 3600
}
```

<Tip>
  Tokens expire after **1 hour**. Cache the token and refresh it before expiry. Avoid calling `/api/auth/v1/token` or `/api/oauth/v1/token` on every request.
</Tip>

## Step 2: Find your Plan ID and Scenario IDs

You need a `planId` and at least one `scenarioId` for every Insights API call.

```bash
curl https://app.simcel.io/api/insights/v1/plans \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## Step 3: Call your first Insights endpoint

Let's fetch the P&L summary comparing two scenarios:

<CodeGroup>
```bash cURL
curl "https://app.simcel.io/api/insights/v1/pnl-summary?planId=plan_9xKz2&scenarioIds=scen_abc,scen_def&interval=FY&currency=USD" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```python Python
import requests

headers = {"Authorization": f"Bearer {token}"}

resp = requests.get(
    "https://app.simcel.io/api/insights/v1/pnl-summary",
    headers=headers,
    params={
        "planId": "plan_9xKz2",
        "scenarioIds": "scen_abc,scen_def",
        "interval": "FY",
        "currency": "USD",
    }
)

data = resp.json()
for scenario in data["scenarios"]:
    print(f"{scenario['scenarioName']}: EBIT = {scenario['pnl']['ebit']:,}")
```

```javascript Node.js
const params = new URLSearchParams({
  planId: "plan_9xKz2",
  scenarioIds: "scen_abc,scen_def",
  interval: "FY",
  currency: "USD",
});

const resp = await fetch(
  `https://app.simcel.io/api/insights/v1/pnl-summary?${params}`,
  { headers: { Authorization: `Bearer ${accessToken}` } }
);

const data = await resp.json();
```
